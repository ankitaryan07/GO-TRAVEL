📌 Project Overview

GO-TRAVEL is a comprehensive full-stack travel booking platform that combines modern web development with cutting-edge AI. Built as an MCA final-year project, it demonstrates expertise in backend architecture, intelligent recommendation systems, real-time payment processing, and user-centric design. The platform enables users to discover destinations, book accommodations, plan itineraries with AI assistance, and complete secure payments.

🚀 Getting Started

Installation and setup guide

📋 Prerequisites

  • ✓ Python 3.8 or higher
  • ✓ pip (Python package manager)
  • ✓ Ollama (for local LLM deployment)
  • ✓ Modern web browser

⚙️ Installation Steps

1️⃣ Clone Repository
git clone https://github.com/ankitaryan07/GO-TRAVEL.git cd GO-TRAVEL
2️⃣ Create Virtual Environment
# Windows python -m venv venv venv\Scripts\activate # Mac/Linux python3 -m venv venv source venv/bin/activate
3️⃣ Install Dependencies
pip install -r requirements.txt
4️⃣ Configure Environment
cp .env.example .env # Edit .env and add your API keys: # RAZORPAY_KEY_ID, RAZORPAY_KEY_SECRET # SENDGRID_API_KEY, GMAIL_EMAIL, GMAIL_PASSWORD # OLLAMA_API_URL, JWT_SECRET_KEY
5️⃣ Initialize Database
python init_db.py
6️⃣ Start Application
uvicorn app.main:app --reload
7️⃣ Access Platform
Frontend: http://localhost:8000 API Docs: http://localhost:8000/docs Swagger UI: http://localhost:8000/docs ReDoc: http://localhost:8000/redoc
